# 💳 service_transactions

## 🧩 Qué es

**service_transactions** es un script **Lua para YimMenu** (menú de mods para GTA V) que forma parte del pack `SCRIPTS LEGACY` del repositorio RTX-SERVER-.

---

## ⚙️ Qué hace

- 🎮 Añade un **submenú o pestaña** dentro de YimMenu centrado en **transacciones de servicio**.
- 💰 Gestiona **pagos y cobros** relacionados con servicios del juego (negocios, propiedades, etc.).
- 🧾 Permite **modificar o simular transacciones** que normalmente hace el juego de forma automática.
- 📦 Se carga junto a otros scripts del mismo pack legacy.

---

## 🎯 Para qué se usa

- 🖥️ **Servidores privados o uso personal** en GTA V con YimMenu.
- 💵 **Controlar o alterar transacciones** de servicios (ingresos, gastos, cobros de negocios).
- 🏢 **Gestionar pagos** de propiedades y negocios sin esperar los tiempos del juego.
- 🎮 **Entretenimiento y pruebas** dentro del juego.

---

## 📋 Requisitos

- ✅ **YimMenu** instalado y funcionando.
- 📁 Colocar el archivo `.lua` en la carpeta de **scripts** de YimMenu.
- 🎮 **GTA V** (Online o Historia).

---

## 🧠 Resumen

> 💳 **service_transactions** es un script para YimMenu dentro del pack legacy del RTX-SERVER-, usado para **gestionar y modificar transacciones de servicio** en GTA V. 🎮
