# 🇪🇸 Ultimate_Menu ESPAÑOL

## 🧩 Qué es

**Ultimate_Menu ESPAÑOL** es un script **Lua para YimMenu** (menú de mods para GTA V) que forma parte del pack `SCRIPTS LEGACY` del repositorio RTX-SERVER-.

---

## ⚙️ Qué hace

- 🎮 Añade un **menú completo** dentro de YimMenu con múltiples opciones.
- 🇪🇸 Está **traducido al español** para facilitar su uso.
- 🧰 Reúne funciones de **jugador, vehículos, armas, mundo, online y diversión** en un solo menú.
- 📦 Se carga junto a otros scripts del mismo pack legacy.

---

## 🎯 Para qué se usa

- 🖥️ **Servidores privados o uso personal** en GTA V con YimMenu.
- 🎨 **Tener un menú todo-en-uno** en español con opciones variadas.
- 🧩 **Complementar** otros submenús del mismo pack.
- 🎮 **Entretenimiento y personalización** dentro del juego.

---

## 📋 Requisitos

- ✅ **YimMenu** instalado y funcionando.
- 📁 Colocar el archivo `.lua` en la carpeta de **scripts** de YimMenu.
- 🎮 **GTA V** (Online o Historia).

---

## 🧠 Resumen

> 🇪🇸 **Ultimate_Menu ESPAÑOL** es un menú completo para YimMenu dentro del pack legacy del RTX-SERVER-, traducido al español y usado para reunir muchas funciones en un solo script en GTA V. 🎮
