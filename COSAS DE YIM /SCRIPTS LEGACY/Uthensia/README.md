# 🌀 Uthensia

## 🧩 Qué es

**Uthensia** es un script **Lua para YimMenu** (menú de mods para GTA V) que forma parte del pack `SCRIPTS LEGACY` del repositorio RTX-SERVER-.

---

## ⚙️ Qué hace

- 🎮 Añade un **submenú o pestaña** dentro de YimMenu con funciones propias.
- 🧰 Reúne opciones de **jugador, vehículos, mundo o utilidades** en un solo script.
- 📦 Se carga junto a otros scripts del mismo pack legacy.

---

## 🎯 Para qué se usa

- 🖥️ **Servidores privados o uso personal** en GTA V con YimMenu.
- 🎨 **Añadir funciones extra** al menú de mods.
- 🧩 **Complementar** otros submenús del mismo pack.
- 🎮 **Entretenimiento y personalización** dentro del juego.

---

## 📋 Requisitos

- ✅ **YimMenu** instalado y funcionando.
- 📁 Colocar el archivo `.lua` en la carpeta de **scripts** de YimMenu.
- 🎮 **GTA V** (Online o Historia).

---

## 🧠 Resumen

> 🌀 **Uthensia** es un script para YimMenu dentro del pack legacy del RTX-SERVER-, usado para añadir funciones extra al menú en GTA V. 🎮
