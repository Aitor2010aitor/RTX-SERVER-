> [!IMPORTANT]  
> ## 5. **🎮 ERR_GFX_STATE**
> 
> ****QUÉ PASA:** EL JUEGO SE CIERRA O MUESTRA EL ERROR `ERR_GFX_STATE`.**
> 
> ****CÓMO SOLUCIONARLO:****
> 
> 1. **ABRE **GTA V**.**
> 2. **VE A **AJUSTES** Y ENTRA EN **GRÁFICOS**.**
> 3. **BUSCA LA OPCIÓN **GENERADOR DE FOTOGRAMAS** (FRAME GENERATION) Y PONLA EN **DESACTIVADO**.**
> 4. **APLICA LOS CAMBIOS Y **REINICIA EL JUEGO**.**
> 
> **SI NO PUEDES ENTRAR AL JUEGO PARA CAMBIAR EL AJUSTE, DESACTIVA LA OPCIÓN ANTES DE ABRIRLO DESDE EL LANZADOR O EL ARCHIVO DE CONFIGURACIÓN GRÁFICA DE GTA V.**
